# Shraddha Yoga Space — legacy prototype

**The current public website is [shraddhayoga.space](https://shraddhayoga.space/).**

This repository contains an early, incomplete HTML prototype. It is **not** the source of the current premium website and is **not** a safe deployment target for updates to that site. The old `index.html` references `styles.css` and `script.js`, neither of which is present in this repository, and includes placeholder contact information.

For changes to the live studio website, first open its current Site project/source and verify the latest published version, then make incremental edits there. Do not copy this prototype over the live site.

Live-site priorities recorded in October 2026: preserve the existing visual identity; verify class/batch and membership information with the owner; keep the free one-day trial, WhatsApp enquiries, mobile layout, reviews, analytics and search visibility working. No live-site changes are made by this README.
